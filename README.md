# SJTU Canvas 签到提醒

面向 Microsoft Edge 的 Manifest V3 扩展：可视化二维码扫描、可选自动签到、Canvas 签到表格监控和课前提醒。

当前版本：**2.4.0**。本项目由个人维护，与上海交通大学官方无隶属关系。

## 功能

- **语音／字幕触发**：检测到签到提示后立即扫描并加速 15 秒；当前有效签到码出现后才允许提交。
- **屏幕扫描器**：使用系统共享选择器捕获课堂标签页、窗口或屏幕，实时显示扫描画面。
- **ZBar + jsQR**：本地识别多个二维码，支持拖动框选、局部放大和原始截图诊断。
- **自动签到**：读取当前 Edge 的学校登录状态，向固定的学校签到接口提交。严格检查返回结果，避免误报成功。
- **课程监控**：读取 Canvas 签到工具表格，提醒新出现的活动签到。
- **课前提醒**：北京时间提前 30 分钟，支持单双周、起止日期和跨午夜课程。
- **提醒与日志**：页面提示、系统通知、最长 30 秒的提示音，以及本地事件记录。

## 安装

1. 下载仓库源码并解压，或 `git clone https://github.com/determine123/sjtu-canvas-reminder.git`。
2. Edge 地址栏打开 `edge://extensions`，开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中**直接包含 manifest.json 的文件夹**。
4. 将插件固定到工具栏，在 Edge 中完成学校登录，并在插件“设置”中测试通知和声音。

不要直接选择 ZIP。若使用 GitHub 的 Download ZIP，通常要进入解压后的仓库文件夹。
插件运行时依赖该目录，请不要移动或删除。更新同一目录后点击“重新加载”，保留原浏览器设置；换目录安装可能得到独立实例。

## 扫描课堂二维码

1. 点击插件 → **打开屏幕扫描器（推荐）**。
2. 点击“选择课堂画面并开始”，在系统选择器中选择课堂直播标签页、播放器窗口或整个屏幕。不要选择扫描器自身页面。
3. 确认预览中确实包含完整、清晰的二维码。二维码较小时，在预览中拖动框选以放大识别。
4. 右侧诊断显示画面尺寸、累计扫描、二维码数量、引擎和链接类型。黑屏、其他二维码、缺少签到参数会分别提示。

扫描器请求约 10 帧/秒（最高 15），目标扫描周期为 250 ms，实际受来源帧率、解码耗时和浏览器节流影响。首次解码后自动追踪二维码区域，局部成功就跳过全图；局部失效自动回退全画面。网络响应等待不占用解码锁，同一签到的处理中请求去重。最小化、锁屏、休眠或受保护的视频可能无法提供有效画面。
建议共享课堂标签页，并保持独立扫描窗口可见、不要最小化。扫描页中的“检查学校登录”只检查是否存在凭据，不访问签到接口，也不能保证凭据一定有效；没有凭据时可提前打开学校登录页。

页面分别显示实际采集帧率、识别耗时、登录准备与签到接口耗时。直播源本身的延时无法由插件消除。本机合成 1080p 场景一次测量全图约 156 ms、追踪区域约 10 ms，仅代表该测试场景，不是课堂延迟保证。

“用截图检查识别”只做本地解码，**不会提交签到**。导入的原始截图不会上传。

旧版标签页扫描仍保留，但依赖当前标签页和窗口保持前台；优先使用可视化扫描器。

## 语音或字幕触发

语音、字幕中的“签到”“现在扫码签到”等是扫描提示，**不是签到参数**。触发后立即扫描、清除旧的自动追踪位置，并进入 15 秒加速模式（目标周期 100 ms，实际仍受解码和浏览器调度限制）。只有当前画面真正解出有效学校二维码，才会按自动签到开关尝试提交；不会用旧签到链接或一句话猜测签到请求。

### 播放器字幕（无需音频服务）

1. 保持课堂网页打开，在播放器中开启字幕。
2. 开始屏幕扫描后，在“语音与字幕触发”中刷新列表，选中对应的课堂标签页并点击“绑定字幕”。
3. 插件读取该页面及可访问 iframe 中的播放器字幕节点、活动 textTracks 字幕；状态会提示是否读到文本。
4. 停止扫描会停止字幕读取并解除绑定，再次使用需重新绑定。

只绑定用户选择的 sjtu.edu.cn 课堂页面，不扫描全页聊天记录。字幕嵌入视频像素、Windows 实时字幕或其他程序窗口时，DOM 读取无法获取文字；这类情况可改用语音。播放器字段不同仍可能需要适配。

### 共享课堂语音（可选，默认关闭）

1. 勾选“启用共享课堂语音识别”，阅读音频处理说明。
2. 重新选择共享课堂标签页，在系统选择器中勾选“共享标签页音频”；系统/窗口共享是否有音轨取决于浏览器和系统。
3. 扫描启动后会尝试识别共享音轨；必要时点击“启动语音”。没有音轨会明确提示，不会退回麦克风。
4. 可以单独停止语音；停止扫描也会停止语音识别。

**音频可能由浏览器在线语音服务处理。** 该选项默认关闭，启用前由用户选择；插件不保存音频或完整转录，也不自行上传到第三方接口。中文识别取决于 Edge 的 API 和服务可用性，不能保证离线工作。未调用不带音轨参数的 start()，不申请麦克风输入。

音轨识别需浏览器提供 SpeechRecognition / webkitSpeechRecognition 且支持 start(audioTrack)；当前实现对 Chromium / Edge 135 之前的版本禁用该功能。服务不支持、网络异常或语言不可用时显示原因，字幕与二维码扫描仍可独立使用。

过滤“不要签到”“签到结束”和常见功能讨论；重复结果至少间隔 15 秒，同一句话 60 秒内不重复触发。语音或字幕可能误识别，提示只引发提醒和扫描，不单独引发提交。转录/字幕原文仅短暂用于内存匹配和当前页面展示；日志只记录通用事件，不写课堂原文。

API 依据：[Microsoft Edge SpeechRecognition 文档](https://github.com/MicrosoftDocs/edge-developer/blob/main/microsoft-edge/web-platform/speech-recognition-api.md)、[start(audioTrack)](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/start)。Edge 的本地模型及语言支持有限，本项目不声称提供本地中文模型。

## 自动签到

**2.2.1 按维护者要求默认启用自动签到**。首次加载此版本会启用已有安装中的该开关；之后手动关闭会保留选择，不会每次启动强行重开。
开始共享画面前，请检查右侧开关是否符合你的意愿。画面捕获始终需要本人选择与授权。

自动签到只适用于二维码中明确包含 courseCode、rollCallToken、signHistoryId 的学校链接。插件不收集密码，不自动处理验证码、短信或扫码登录。

- 使用当前 Edge 配置中 mlearning 的 token Cookie；没有凭据时会尝试正常初始化学校会话，仍需登录则提示手动处理。
- 只向 `https://mlearning.sjtu.edu.cn/lms-lti-rollcall-sjtu/sign/scan/` 提交，不向任意二维码站点发送凭据。
- HTTP 成功、resultCode 为 200 且 body.status 为 NORMAL 时才显示服务端确认成功。最终请核对学校签到记录。
- 登录准备失败时，可在学校页面完成登录后点击“重新尝试”。
- 超时、未知业务返回或提交后中断不会自动重发；已经发送的请求无法撤回，必须自行核对结果。
- 去重记录使用 SHA-256 标识，只保留结果与时间，最多 200 项、7 天，不保存完整二维码或令牌。

学校接口可能变化；模拟测试不能证明真实课堂接口仍可用。请遵守适用的课堂要求。

## Canvas 课程表格监控

“课程 → 添加监控课程”填写数字课程编号，或课程实际的签到工具地址：

```text
https://oc.sjtu.edu.cn/courses/课程编号/external_tools/工具编号
```

在 Canvas 课程左侧点击“点名签到”，复制地址栏中的地址。纯编号默认使用工具 6650，实际不同则填写完整 URL。
**v.sjtu.edu.cn 的直播地址不属于签到工具地址**，应使用屏幕扫描器。

主动启用“签到表格监控”，保持相应签到页面打开。设置中可以开启自动补齐课程页，并调整 30 秒至 10 分钟的检查间隔。监控会定期刷新专用签到工具页，不要在该页保留未提交表单。

表格识别依赖“签到号／签到编号”“状态”“创建／开始／发起时间”等列。首次为活动签到、新活动记录或状态转为活动时提醒；已签到和未知状态不误报活动签到。
课程基准与开关持久化，Edge 重启后恢复。界面提示等待打开、需要登录、页面休眠或等待表格；字段和域名变化可能需要适配。

## 课前提醒

在“课程”中添加课程名称、上课日、时间、日期范围和地点，主动启用课前提醒。
全部按北京时间计算，提前 30 分钟。单双周需填写学期第一周的周一日期。

跨午夜课程在前一天提醒；休眠恢复后尚未开课可补报，开课后不补报。课程和开关持久化，Edge 启动后恢复调度。
调课需要调整记录；不自动同步校历、节假日或学校课表。
浏览器关闭或电脑休眠期间不能保证提醒准时送达。

## 更新源码并同步 GitHub

本仓库源码是维护入口。修改并验证后，在 PowerShell 执行：

```powershell
.\tools\publish.ps1 -Message "描述这次更新"
```

Windows 也可双击 `更新并同步GitHub.cmd`。脚本会：

1. 运行回归与资源检查。
2. 检查 GitHub 是否已有未合并的新提交，避免覆盖远端工作。
3. 如配置了本机安装目录，直接覆盖运行所需文件，不生成本地 ZIP。
4. 提交已跟踪文件的修改并推送 main，核对远端提交。

新文件必须先检查并 `git add`，或通过 `-IncludePaths` 显式传入。需要本机已有 GitHub 推送权限；脚本不保存令牌，也不会强制推送。
**随手编辑文件不会自行上传**；使用此脚本，或常规的 git commit / git push。项目 AGENTS.md 已记录后续开发完成后同步远端的要求。

`.publish-local.json` 为忽略的本机配置，例如：

```json
{
  "node": "node",
  "python": "python",
  "installDirectories": ["D:/your-installed-extension"]
}
```

安装目录必须已含同名插件 manifest.json。源码覆盖后，还需在 Edge 扩展页重新加载。不要把本机配置提交到 GitHub。

## 测试与构建

使用 Node.js 24、Python 3.9+：

```text
node --test tests/core.test.cjs tests/worker.test.cjs tests/auto-sign.test.cjs tests/hints.test.cjs
python tools/validate.py
```

27 项逻辑回归覆盖校验、防重、结果判定、登录失败、超时、取消、调度和设置迁移。
`tests/browser-smoke.cjs` 与 `tests/screen-smoke.cjs` 还可使用 Playwright 和 Edge 执行浏览器测试：

```text
npm install --no-save playwright
node tests/browser-smoke.cjs
node tests/screen-smoke.cjs
node tests/hints-browser.cjs
```

可以通过 SJTU_PLAYWRIGHT_MODULE、SJTU_EDGE_PATH 指定模块或 Edge 路径。
浏览器测试使用合成课堂帧、模拟学校 Cookie/接口/系统通知；ZBar WASM 实际在浏览器中执行。测试图包含多二维码和全高清角落小二维码。没有用户课堂截图或真实登录数据。新增提示测试覆盖实际 DOM 字幕绑定、共享音轨传入、否定表达、无二维码绝不提交、后续出现二维码才模拟提交、停止时解除绑定。语音服务的转录和学校接口在该测试中模拟，不能证明真实中文识别准确率。
尚未验证每个真实课堂的画质、屏幕共享授权、Windows 提醒和学校实际接口。

GitHub Actions 在推送后自动运行回归、检查资源并构建安装产物；进入 Actions 中成功的运行下载 Artifacts。构建不要求个人账号或令牌。
手动运行 `python package.py` 可生成 dist/ 中的 ZIP，解压后 manifest.json 直接位于根目录，不再多套一层。

## 隐私与权限

- 画面只在本机内存识别，不上传、不存储；原始截图诊断不执行签到。
- 可选语音识别使用用户授权的共享音轨，可能由浏览器在线服务处理；不读取麦克风，不在插件中保存音频。字幕匹配在本机进行，完整课堂文本不写日志。
- 完整二维码链接仅存浏览器 session，不写日志；关闭浏览器后不保留链接。
- cookies 权限只用于读取学校登录凭据；凭据不写源码、日志或本地配置。
- storage 保存课程、课表、偏好、事件基准和摘要结果，不使用云同步。
- 学校域名权限用于课程表格和签到请求；activeTab / scripting 用于手动开启的旧标签页扫描。
- notifications / offscreen 用于提醒；alarms 用于课程检测和课前调度。
- 屏幕扫描器的共享由系统选择器授权，本地 WebAssembly 需 wasm-unsafe-eval CSP。
- 不使用手机推送、不加载远程脚本，不读取其他浏览器配置。
